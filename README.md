# Физтех.Навигатор

## Сборка 2026.11.14-r3

[Проверка запуска и публичного адреса](docs/Deployment-r3.md).

Демонстрационная версия локального помощника по административным регламентам. В каталоге corpus находятся четыре синтетических документа в форматах PDF, DOCX и XLSX. Система использует BM25, RuBERT и локальный Qwen2.5-1.5B-Instruct. Новые документы можно загрузить в разделе «Библиотека». Файлы и индекс из пользовательской загрузки хранятся отдельно для каждой сессии. В публичной демонстрации используйте учебные данные.

## Проверка нового регламента

В разделе «Библиотека» загрузите файл [example-spectrometer.docx](materials/example-spectrometer.docx) и нажмите «Индексировать». В разделе «Навигатор» выберите в боковом меню только этот файл и задайте вопрос «Как получить спектрометр? Опишите весь порядок выдачи». У шагов должны открываться исходные пункты и даты. Условия и зависимости доступны также в выгрузке JSON.

## Запуск

Для Python 3.12 установите системный C++ компилятор и CMake. Откройте терминал в корне репозитория и выполните команды.

```sh
python -m pip install -r requirements.txt
python scripts/fetch_model.py
python -m streamlit run app.py
```

Для Streamlit Community Cloud укажите ветку загруженного кода, Python 3.12 и файл hosted_app.py. При первом старте специальная точка входа скачивает публичные веса Qwen и модели повторного ранжирования с Hugging Face с проверкой SHA-256. После этого модель отвечает на сервере приложения. Для Docker выполните python scripts/fetch_model.py и docker compose up --build. В локальной версии генерация не требует сетевого доступа.
