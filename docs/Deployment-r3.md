## Как проверить адрес для жюри

Для публикации распакуйте публичный комплект, разместите файлы в GitHub и в Streamlit Community Cloud выберите этот репозиторий, Python 3.12 и точку входа `hosted_app.py`. Домашняя страница должна открываться из приватного окна без входа в аккаунт. Можно сначала проверить вручную, загрузив `materials/example-spectrometer.docx`, выбрав этот документ и задав вопрос «Как получить спектрометр? Опишите весь порядок выдачи».

Для автоматической проверки выполните команды из публичного комплекта на компьютере проверяющего. Укажите фактический публичный адрес приложения. Проверка отправляет только синтетический DOCX и заданный учебный вопрос.

```sh
python -m pip install playwright python-docx
python -m playwright install chromium
python scripts/check_deploy.py https://<ваше-приложение>.streamlit.app --out deployment-check.json
```

Скрипт открывает новую сессию браузера, проверяет версию, загружает учебный файл, задаёт вопрос, скачивает ответ и проверяет ссылки, зависимость и открытие основания. Если облако выдаёт ошибку загрузки весов или возвращает пустой экран, проверка завершается ошибкой. Локально команду можно проверить на `http://127.0.0.1:8501` после старта приложения.
